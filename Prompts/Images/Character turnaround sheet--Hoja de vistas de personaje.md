# Character turnaround sheet / Hoja de vistas de personaje

## English

```text
Draw [character description] from front, side, back, and three-quarter views. Use a neutral standing pose, shared scale and baseline, and consistent costume details across the four views.
```

## Spanish

```text
Dibuja [descripción del personaje] de frente, perfil, espalda y tres cuartos. Usa una pose neutra de pie, escala y línea de suelo comunes, y detalles de vestuario coherentes en las cuatro vistas.
```
