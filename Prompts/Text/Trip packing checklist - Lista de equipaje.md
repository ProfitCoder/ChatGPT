# Trip packing checklist / Lista de equipaje

## English

```text
Create a packing checklist for [destination], [duration], and [activities] with [baggage limit]. Separate what to pack from what to check before departure and explain which items can be shared.
```

## Spanish

```text
Prepara una lista de equipaje para [destino], [duración] y [actividades] con [límite de equipaje]. Distingue qué llevar de qué comprobar antes de salir e indica qué artículos se pueden compartir.
```
