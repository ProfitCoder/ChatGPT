# Review HTML accessibility / Revisar accesibilidad HTML

## English

```text
Review [HTML and CSS] for semantics, form labels, keyboard access, and visible focus. Point to each affected element and propose the smallest markup or style correction.
```

## Spanish

```text
Revisa [HTML y CSS] para comprobar semántica, etiquetas de formulario, acceso por teclado y foco visible. Señala cada elemento afectado y propone el cambio mínimo de estructura o estilo.
```
