# Isometric room illustration / Ilustración isométrica de una habitación

## English

```text
Illustrate [room type] as an isometric cutaway with two visible walls. Place [key objects] at a consistent scale and use a unified light direction to make the layout easy to read.
```

## Spanish

```text
Ilustra [tipo de estancia] como un corte isométrico con dos paredes visibles. Coloca [objetos principales] a escala coherente y usa una sola dirección de luz para facilitar la lectura de la distribución.
```
