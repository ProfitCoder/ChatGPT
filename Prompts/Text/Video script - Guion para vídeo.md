# Video script / Guion para vídeo

## English

```text
Write a [duration] video script on [topic] for [audience]. Pair narration with visual cues and estimated timings, and give the viewer a practical takeaway in the final segment.
```

## Spanish

```text
Escribe un guion de [duración] sobre [tema] para [público]. Acompaña la narración con indicaciones visuales y tiempos estimados y termina con una aplicación práctica para el espectador.
```
