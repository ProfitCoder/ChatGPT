# Debug an error / Diagnosticar un error

## English

```text
Given [code], [error], and [environment], identify the most likely cause and cite the relevant line. Suggest the smallest fix and a way to verify it with representative input.
```

## Spanish

```text
Con [código], [error] y [entorno], identifica la causa más probable y señala la línea relevante. Propón el cambio mínimo y cómo verificarlo con una entrada representativa.
```
