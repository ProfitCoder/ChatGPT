# Carousel art direction / Dirección visual de carrusel

## English

```text
Create a contact sheet with [number] equal portrait panels for a carousel about [topic]. Give each panel a distinct visual idea while keeping background, margins, and illustration style consistent. Leave room for editable captions.
```

## Spanish

```text
Crea una hoja con [cantidad] paneles verticales iguales para un carrusel sobre [tema]. Da a cada panel una idea visual distinta y mantén fondo, márgenes y estilo de ilustración coherentes. Deja espacio para pies editables.
```
