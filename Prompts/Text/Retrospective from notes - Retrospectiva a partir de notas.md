# Retrospective from notes / Retrospectiva a partir de notas

## English

```text
Use [notes] from [period] to identify recurring obstacles and practices worth keeping. Turn the top obstacle into a one-week experiment with an owner and an observable result.
```

## Spanish

```text
Usa [notas] de [periodo] para identificar obstáculos recurrentes y prácticas que conviene mantener. Convierte el principal obstáculo en un experimento de una semana con responsable y resultado observable.
```
