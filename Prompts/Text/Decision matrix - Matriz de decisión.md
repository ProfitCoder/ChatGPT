# Decision matrix / Matriz de decisión

## English

```text
Compare [options] using [criteria] and [weights]. Show the scoring scale and evidence for each score, then recalculate after changing the weight of the most uncertain criterion.
```

## Spanish

```text
Compara [opciones] con [criterios] y [pesos]. Muestra la escala y evidencia de cada puntuación. Recalcula al modificar el peso del criterio más incierto.
```
