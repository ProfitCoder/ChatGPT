# Extend an image canvas / Ampliar el lienzo de una imagen

## English

```text
Extend [reference image] toward [sides] to reach [aspect ratio]. Continue the horizon, perspective lines, and textures into the new space while keeping the original area intact.
```

## Spanish

```text
Amplía [imagen de referencia] por [lados] hasta alcanzar [relación de aspecto]. Prolonga el horizonte, las líneas de perspectiva y las texturas en el nuevo espacio, manteniendo intacta el área original.
```
