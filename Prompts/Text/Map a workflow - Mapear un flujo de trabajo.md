# Map a workflow / Mapear un flujo de trabajo

## English

```text
Map [current process] from its trigger to completion. Identify handoffs, inputs, outputs, and common exceptions. Propose one automation and state when a person should intervene.
```

## Spanish

```text
Representa [proceso actual] desde el evento que lo inicia hasta el cierre. Identifica traspasos, entradas, salidas y excepciones habituales. Propón una automatización e indica cuándo debe intervenir una persona.
```
