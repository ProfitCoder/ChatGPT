# Educational process illustration / Ilustración de un proceso educativo

## English

```text
Illustrate [ordered stages] of [process] as equal panels. Use repeated viewpoints to make changes visible, place simple arrows between stages, and reserve blank areas for labels to be added later.
```

## Spanish

```text
Ilustra [etapas ordenadas] de [proceso] en paneles iguales. Repite el punto de vista para mostrar los cambios, coloca flechas sencillas entre etapas y reserva espacios para añadir etiquetas después.
```
