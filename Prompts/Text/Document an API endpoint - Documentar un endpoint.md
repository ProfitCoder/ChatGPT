# Document an API endpoint / Documentar un endpoint

## English

```text
Document [endpoint specification] with its method, parameters, response fields, error cases, and a request and response example. Flag any behavior the specification leaves open.
```

## Spanish

```text
Documenta [especificación del endpoint] con método, parámetros, campos de respuesta, errores y un ejemplo de petición y respuesta. Señala el comportamiento que la especificación deja abierto.
```
