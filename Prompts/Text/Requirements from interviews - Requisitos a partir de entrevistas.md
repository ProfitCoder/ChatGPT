# Requirements from interviews / Requisitos a partir de entrevistas

## English

```text
Extract candidate requirements from [interview excerpts]. Link each requirement to its source, identify conflicting needs, and draft one acceptance criterion for each confirmed requirement.
```

## Spanish

```text
Extrae posibles requisitos de [fragmentos de entrevistas]. Vincula cada requisito con su fuente, identifica necesidades contradictorias y redacta un criterio de aceptación por requisito confirmado.
```
