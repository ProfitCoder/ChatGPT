# Explain a code trace / Seguir la ejecución de código

## English

```text
Trace [code] with [input] in [language]. Show the changing variables at each meaningful step and identify the first point where the result diverges from [expected output].
```

## Spanish

```text
Sigue la ejecución de [código] con [entrada] en [lenguaje]. Muestra cómo cambian las variables en cada paso relevante e identifica dónde empieza a desviarse de [resultado esperado].
```
