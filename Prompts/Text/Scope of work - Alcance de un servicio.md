# Scope of work / Alcance de un servicio

## English

```text
Turn [client brief] into a scope of work. Describe deliverables, acceptance criteria, milestones, client inputs, and how to request changes. Mark unresolved estimates as pending.
```

## Spanish

```text
Convierte [encargo del cliente] en un alcance de trabajo. Describe entregables, criterios de aceptación, hitos, aportaciones del cliente y cómo solicitar cambios. Marca como pendientes las estimaciones abiertas.
```
