# Website hero image / Imagen de cabecera web

## English

```text
Generate a wide hero image for [site purpose]. Place [focal subject] in the right third and leave the left half quiet and dark enough for white overlay text. Keep key details inside the center for tighter crops.
```

## Spanish

```text
Genera una cabecera panorámica para [objetivo del sitio]. Coloca [sujeto principal] en el tercio derecho y deja la mitad izquierda despejada y oscura para superponer texto blanco. Mantén los detalles importantes dentro de la zona central para recortes más cerrados.
```
