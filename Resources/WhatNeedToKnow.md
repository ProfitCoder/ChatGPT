# Conceptos esenciales para trabajar con IA

Un asistente como ChatGPT puede ayudarte a preparar un borrador, explicar código, organizar información o plantear formas de resolver un problema. Para obtener una respuesta que puedas revisar, facilita el material de partida y especifica qué resultado necesitas.

## Qué información conviene proporcionar

- **Contexto.** Indica el propósito de la tarea y quién usará el resultado.
- **Material de partida.** Adjunta el fragmento de código, texto o tabla pertinente.
- **Condiciones.** Especifica requisitos como el idioma, la extensión, la versión del software o los datos que deben conservarse.
- **Formato de entrega.** Pide el resultado en el formato que usarás, como una tabla, un bloque de código o una lista de pasos.

## Cómo comprobar el resultado

| Si la respuesta contiene… | Comprueba… |
| --- | --- |
| Código | Que se ejecuta en tu entorno y funciona con entradas habituales y casos límite. |
| Cálculos | Que las unidades, los signos y los totales coinciden con los datos de origen. |
| Citas o enlaces | Que la fuente existe y respalda la afirmación concreta. |
| Un resumen | Que conserva fechas, cifras y conclusiones relevantes del documento original. |
| Información actual | Que la fuente está vigente y se aplica a la versión o al periodo consultado. |

ChatGPT puede generar afirmaciones incorrectas con un tono convincente. Cuando un dato afecte al resultado, contrástalo con su fuente original. Si faltan datos, pide que se indiquen explícitamente los supuestos y las preguntas pendientes. [OpenAI Help Center](https://help.openai.com/en/articles/8313428-does-chatgpt-tell-the-truth)

## Ejemplo

Si necesitas entender un error de PHP, adjunta el mensaje exacto, el fragmento que lo provoca y la entrada utilizada. Pide que se señale la línea relevante, se proponga el cambio mínimo y se indique cómo comprobarlo con la misma entrada.

Puedes adaptar ese patrón a otras tareas con la [guía para escribir prompts](Prompt-Writing-Guide.md).
