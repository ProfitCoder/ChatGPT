# Consistent icon set / Conjunto de iconos coherente

## English

```text
Create a set of icons for [concept list] in a grid. Use a shared stroke width, corner radius, and optical size. Give each icon its own cell and leave enough padding for individual cropping.
```

## Spanish

```text
Crea iconos para [lista de conceptos] en una cuadrícula. Usa grosor de trazo, radio de esquinas y tamaño óptico comunes. Da a cada icono su propia celda con margen suficiente para recortarlo.
```
