# Task prioritization / Priorización de tareas

## English

```text
Rank [tasks] against [goal] using impact, urgency, effort, and dependencies. Show the criteria in a table and propose a first action for the top three.
```

## Spanish

```text
Ordena [tareas] según [objetivo] usando impacto, urgencia, esfuerzo y dependencias. Muestra los criterios en una tabla y propone una primera acción para las tres primeras.
```
