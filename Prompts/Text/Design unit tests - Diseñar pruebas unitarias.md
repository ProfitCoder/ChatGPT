# Design unit tests / Diseñar pruebas unitarias

## English

```text
Write unit tests for [function] using [framework]. Cover normal inputs, boundaries, and documented failures. Give each test a descriptive name and state any assumption about the contract.
```

## Spanish

```text
Escribe pruebas unitarias para [función] con [framework]. Cubre entradas normales, límites y errores documentados. Da un nombre descriptivo a cada prueba e indica cualquier supuesto sobre el contrato.
```
