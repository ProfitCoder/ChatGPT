# Automation specification / Especificación de una automatización

## English

```text
Design a recurring workflow for [task] using [available tools]. Specify schedule, inputs, output destination, failure notification, and how retries avoid duplicate results.
```

## Spanish

```text
Diseña un flujo recurrente para [tarea] con [herramientas disponibles]. Especifica horario, entradas, destino de los resultados, aviso de fallos y cómo evitar duplicados al reintentar.
```
