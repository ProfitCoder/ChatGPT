# Weekly planning / Planificación semanal

## English

```text
Build a weekly plan from [tasks], [deadlines], and [available hours]. Estimate each block, reserve buffer time, and explain what to defer if the work exceeds capacity.
```

## Spanish

```text
Crea un plan semanal con [tareas], [plazos] y [horas disponibles]. Estima cada bloque, reserva margen y explica qué aplazar si el trabajo supera el tiempo disponible.
```
