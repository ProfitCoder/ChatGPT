# Compare source claims / Comparar afirmaciones entre fuentes

## English

```text
Compare what [sources] say about [question]. Build a table of claims, supporting excerpts, and disagreements. Mark where the available evidence leaves the question open.
```

## Spanish

```text
Compara lo que [fuentes] afirman sobre [pregunta]. Crea una tabla de afirmaciones, fragmentos que las sustentan y discrepancias. Indica dónde la evidencia disponible deja abierta la pregunta.
```
