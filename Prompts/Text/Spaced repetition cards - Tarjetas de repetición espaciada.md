# Spaced repetition cards / Tarjetas de repetición espaciada

## English

```text
Turn [notes] into question-and-answer flashcards. Test one idea per card, include examples for easily confused concepts, and return two tab-separated columns for import.
```

## Spanish

```text
Convierte [apuntes] en tarjetas de pregunta y respuesta. Evalúa una idea por tarjeta, incluye ejemplos de conceptos que se confunden y devuelve dos columnas separadas por tabuladores para importar.
```
